Bytebase se sitúa entre tu equipo y tus bases de datos para gobernar cómo se accede a los datos y cómo se modifican.

- **Espacio de trabajo:** Todo lo que tu equipo administra conjuntamente en Bytebase.
- **Proyecto:** Agrupa bases de datos, personas y flujos de trabajo. Aquí se trabaja con las bases de datos.
- **Instancia:** Un servidor o clúster de bases de datos conectado a Bytebase. Una instancia puede alojar varias bases de datos.
- **Base de datos:** Una base de datos individual dentro de una instancia. Cada base de datos pertenece a un solo proyecto.

Cuando una base de datos pertenece a un proyecto:

- **Consultar datos:** Usa SQL Editor para explorar esquemas, tablas y datos.
- **Cambiar datos:** Usa un flujo de trabajo revisado y registrado en lugar de realizar cambios directamente.
