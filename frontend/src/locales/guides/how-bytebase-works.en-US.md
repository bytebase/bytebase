Bytebase sits between your team and your databases, governing how data is accessed and changed.

- **Workspace:** Everything your team manages together in Bytebase.
- **Project:** Groups databases, people, and workflows. This is where database work happens.
- **Instance:** A database server or cluster connected to Bytebase. One instance can host multiple databases.
- **Database:** An individual database on an instance. Each database belongs to one project.

With a database in a project:

- **Query data:** Use SQL Editor to explore schemas, tables, and data.
- **Change data:** Use a reviewed and recorded workflow instead of making changes directly.
